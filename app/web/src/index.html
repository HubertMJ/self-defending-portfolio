About

About me

I have been a Cyber Security Engineer at SecureVisio in Rzeszów, Poland, since March 2020. I started on the detection side: writing SIEM correlation rules based on MITRE ATT&CK techniques, generating events and reading the logs to see what a rule really catches, and turning that into incident-handling scenarios for SOC teams. I love automating things: if I have done something twice, the third time a script does it.

Much of my work today is building with AI. I created a workflow that uses AI to convert publicly available compliance rules based on NIST recommendations into a format SecureVisio can import. The compliance rules and reports it produced ship with the application. Now I am designing a broader workflow in which AI builds the product's content: compliance, scenarios, integrations and parsers. I am also building an MCP module that lets AI work with SecureVisio directly.

Alongside that I look after the platform around the product. I designed a system that builds demo environments on demand, keep the SecureVisio demo platform running, integrate external applications through its REST API and write the guides for both. I turn what the product needs into requirements that developers build changes from, and track down and test what goes wrong. Under it all are the internal environments I run, from the hardware in the server room up, and the tools I write for the team: PowerShell scripts, test tooling and the CI/CD pipelines that build them.

At home I run a homelab on a Proxmox server, and this site lives there too: the k3s cluster that defends itself in public and the OpenSearch SIEM that watches it, each in its own VLAN, with a Cloudflare Tunnel as the only way in from the internet. Around them run the everyday services: Home Assistant, my own DNS and reverse proxy, a Grafana, Loki and VictoriaMetrics monitoring stack fed by NetFlow and UniFi metrics, CrowdSec, and Immich for photos.
